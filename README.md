**IT Support & Infrastructure**
- Troubleshooting hardware dan software untuk workstation, server, dan perangkat jaringan
- Instalasi, konfigurasi, dan maintenance sistem operasi Windows, Linux, dan macOS
- Manajemen Active Directory, Group Policy, dan user management
- Setup dan maintenance jaringan LAN/WAN, termasuk konfigurasi router, switch, dan firewall
- Remote desktop support dan remote troubleshooting
- Dokumentasi teknis dan pembuatan knowledge base
- IT asset management dan inventory control
- Help desk ticketing system management

**Cybersecurity**
- Security assessment dan vulnerability scanning menggunakan tools seperti Nmap, Nessus, dan OpenVAS
- Implementasi dan monitoring security controls (firewall rules, IDS/IPS, antivirus)
- Security incident response dan forensik digital dasar
- Penetration testing untuk mengidentifikasi kelemahan sistem
- Security awareness training untuk end-users
- Backup dan disaster recovery planning
- Log analysis dan SIEM monitoring
- Compliance dengan standar keamanan (ISO 27001, NIST framework)
